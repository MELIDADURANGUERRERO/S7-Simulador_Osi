# S7-Simulador_Osi
Proyecto desarrollado con fines académicos
para demostrar de manera práctica el
funcionamiento del encapsulamiento y desencapsulamiento de datos mediante el Modelo OSI.

**Descripción**

El simulador fue desarrollado en Python y representa la comunicación entre PC-A y PC-B, mostrando el recorrido de la información a través de las siete capas del Modelo OSI. Permite visualizar el proceso de encapsulamiento, la transmisión simulada y el desencapsulamiento hasta recuperar el mensaje original.

**Características**
Representación de las 7 capas del Modelo OSI.
Encapsulamiento de datos en PC-A.
Desencapsulamiento de datos en PC-B.
Uso de Base64 en la capa de Presentación.
Simulación del tránsito de información.
Verificación del mensaje original.

**Tecnologías utilizadas**
Python
Tkinter
Base64
Threading

**Para ejecutar el simulador:**
python S7_simulador_osi.py
